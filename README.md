# KDE 6 Ricing Configs

This repository contains most of my configuration files for ricing KDE 6. It includes visual tweaks and a music equalizer setup.

## Applications Used

- **[Force Blur (iGerman00 fork)](https://github.com/iGerman00/kwin-effects-forceblur)**  
  A better blur effect for a liquid glass style transparencies  
  - [View Configs](/better-blur)

- **[JamesDSP (JDSP4Linux)](https://github.com/Audio4Linux/JDSP4Linux)**  
  Audio equalizer for music  
  - [View Configs](/JamesDSP)

- **[FastFetch](https://github.com/fastfetch-cli/fastfetch)**  
  Lightweight system info fetcher  
  - [View Configs](/fastfetch)

- **[Klassy](https://github.com/paulmcauley/klassy)**  
  Custom window decorator for a more refined look  
  - [View Configs](/Klassy)

- **[Rounded Corners](https://github.com/matinlotfali/KDE-Rounded-Corners)**  
  Enhances rounded corners across KDE  
  - [View Configs](/Rounded-Corners)

- **[Oh My Posh](https://github.com/JanDeDobbeleer/oh-my-posh)**  
  Customizable shell prompt renderer  
  - [View Configs](/ohmyposh)
